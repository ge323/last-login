실종된 직원의 PC를 정리하라는 지시를 받았다. 그런데 그녀의 메신저는 어제도 접속되어 있었다.

가짜 사내 OS 화면 위에서 진행되는 공포 추리 게임 프로토타입입니다. 메일, 메신저, 파일, 휴지통, 접속 기록을 뒤져 사건의 진실을 맞히세요.

플레이
브라우저에서 index.html을 열거나, GitHub Pages 주소로 접속하세요.
플레이 시간: 약 10~15분
엔딩: 6종 (숨겨진 엔딩 1종 포함)
조작
아이콘을 클릭하면 앱이 열립니다.
창 제목 표시줄을 드래그하면 창을 옮길 수 있습니다.
중요한 단서는 '단서 수첩'에 자동으로 기록됩니다.
확신이 서면 '보고서 제출'에서 세 가지 질문에 답하세요.
기술
빌드 과정 없는 순수 웹 기술
index.html: 화면 뼈대 (시작 화면, 잠금 화면, 바탕화면, 작업표시줄)
style.css: 디자인과 연출 (색감, 주사선, 글리치 애니메이션)
script.js: 게임 로직 (창 관리, 단서, 암호, 원격 이벤트, 엔딩)
폰트: Google Fonts (IBM Plex Sans KR, Nanum Gothic Coding)
주의

이 게임에 나오는 회사, 인물, 사건은 모두 허구입니다.
